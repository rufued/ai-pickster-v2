# AI brand assets

- OpenAI: OpenAI Blossom path from Simple Icons v14.15.0; displayed unchanged and used only to identify GPT/OpenAI. See https://openai.com/brand/.
- Google Gemini, Anthropic, DeepSeek: SVG paths from the version-pinned `simple-icons` package. See https://simpleicons.org/.
- Grok/xAI: initials fallback. Simple Icons does not currently include xAI, and the official asset download was unavailable during implementation. See https://x.ai/legal/brand-guidelines.
